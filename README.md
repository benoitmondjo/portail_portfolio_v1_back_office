# Projet portail des portfolios
## Paretie Back Office
### Où écrire mon code ?
Pour tous les developpeurs du Back Ofiice, vos travaillerez dans le dossier *** app ***
Suivant les taches à réaliser, vous travaillerez dans:
- /app/auth/connexion/page.tsx : pour la page de connexion de l'admin
- /app/auth/uodate/page.tsx : pour la page qui permettra à l'admin de modifier son *** nom *** , ***  mot de passe *** etc

- /app/dashboard/page.tsx : pour la page dashboard
- /app/dashboard/profile/create/page.tsx : pour la page qui peremet d'ajouter un portfolio
- /app/dashboard/profile/read/page.tsx : pour la page qui permet de voir un portfolio
- /app/dashboard/profile/update/page.tsx : pour la page qui peremet de modifier un portfolio


### Rappel des technologies utilisées
- *** HTML ***
- *** Tailwind CSS ***
- *** TypeSript  ***
- *** Next JS *** au *** lieu de React JS ***
